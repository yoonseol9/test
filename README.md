# 우리들의 방명록

GitHub Pages용 공유 방명록입니다. 프론트엔드는 GitHub Pages, 데이터 저장/실시간 동기화는 Supabase를 사용합니다.

## 1. Supabase 테이블 생성
Supabase SQL Editor에서 실행:

```sql
create table public.guestbooks (
  id bigint generated by default as identity primary key,
  name text not null check (char_length(name) between 1 and 20),
  message text not null check (char_length(message) between 1 and 200),
  created_at timestamptz not null default now()
);

alter table public.guestbooks enable row level security;

create policy "public can read guestbooks"
on public.guestbooks for select to anon using (true);

create policy "public can insert guestbooks"
on public.guestbooks for insert to anon with check (true);
```

## 2. script.js 설정
Supabase Project URL과 anon/publishable key를 `script.js`의 두 상수에 입력합니다. 서비스 롤 키는 절대 넣지 않습니다.

## 3. GitHub Pages
Repository Settings → Pages → Deploy from a branch → `main` / `/ (root)`를 선택합니다.
